# Removable modular trays

- **State:** `CONCEPT_PROPOSED`; no physical fit, retention or ergonomic test.
- **Function:** organize objects into separately removable/reconfigurable groups.
- **Alternatives:** neighboring open-top bins; stacked trays; bins in a shared carrier; guided drawers.
- **Selection conditions:** lift-out bins suit frequent rearrangement and overhead access. Stacks save plan area but hide lower contents and require vertical clearance. A shared carrier limits loose movement but adds interfaces. Drawers add guidance/retention and need pull-out clearance.
- **Interfaces:** bin-to-base support and lateral registration; positive retention if transported, tilted or bumped. Gravity-only support does not retain under inversion or impact.
- **Space checks:** include object dimensions/orientation, finger access, divider thickness, removal path, carrier wall and external installation allowance. Nominal bin volume is not useful capacity unless object occupancy is measured.
- **Risks:** unknown object envelope/count, bins sliding or lifting unexpectedly, finger access blocked by tall partitions, tolerance stack-up.
- **Evidence:** concept notes only; `NOT_EVALUATED` for any specific application.
