# Removable guided support

- **State:** `CONCEPT_PROPOSED`; no load, fatigue, anchor or physical cycling test.
- **Function:** position a serviceable object relative to a mounting surface and allow removal.
- **Alternatives:** screw directly through the object; slide/key into a wall plate plus independent retainer; captive hook/snap; strap on a cradle; hinged access.
- **Selection conditions:** sliding guides help repeatable location; they do not alone prevent motion along the slide axis. Use a distinct stop/lock where gravity, vibration or orientation could release the part. Screws offer positive clamping but increase service steps. Straps accommodate uncertain envelopes but depend on strap path and object features.
- **Interfaces:** mounting surface and anchor pattern, equipment datum/envelope, load path, insertion/removal trajectory, retainer access. Unknown substrate/anchor data blocks load approval.
- **Space checks:** include anchor head/tool access, removal sweep, connector/cable envelope and loaded deflection allowance.
- **Predicted risks:** anisotropic FDM strength, layer peel, creep, stress concentration, anchor pull-out, loose retainer. These are risks, not observed failures in a named test.
- **Evidence:** concept only; `NOT_EVALUATED` for strength, life and installed compatibility.
