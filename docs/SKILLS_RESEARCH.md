## Compatibilidade e segurança

O Codex usa skill folder com `SKILL.md` contendo frontmatter `name`/`description`, e arquivos auxiliares podem ser lidos sob demanda. A skill deste repositório usa esse formato e está exposta como skill repo-scoped em `.agents/skills/3d-engineering` para o checkout, além de existir em `skills/3d-engineering` como conteúdo versionado. O teste final depende do mecanismo de descoberta da instalação local.

Nenhum candidato revisado é tratado como confiável só por ser uma skill. Não foram executados `setup.sh`, scripts de servidor, código JavaScript de review UI nem instaladores remotos.

## MCP

Não foi encontrado candidato oficial build123d/OCP/FreeCAD com manutenção, segurança e benefício operacional suficientes para implantar. MCP é adiado. O CLI proporciona operação local determinística e reportável; um MCP poderia ser proposto mais tarde para leitura/inspeção interativa da geometria, sujeito a auditoria do servidor e teste de isolamento.
